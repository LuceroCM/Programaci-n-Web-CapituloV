Ejercicio 8.1: Verdadero o Falso

a) El caso default es requerido en la instrucción de selección switch.

: El caso default es opcional. Si no se necesita realizar una acción predeterminada, entonces no hay necesidad de un caso default.

b) La instrucción break es requerida en el último caso de una instrucción de selección switch.

: La instrucción break se utiliza para salir de switch. La instrucción break no se requiere para el último caso en switch.

c) La expresión ( x > y && a < b ) es verdadera si x > y es verdadera, o si a < b es verdadera.

: Ambas expresiones relaciónales deben ser verdaderas para que toda la expresión sea verdadera cuando se utilice el operador &&.

d) Una expresión que contiene el operador || es verdadera si uno o ambos de sus operandos son verdaderos.
