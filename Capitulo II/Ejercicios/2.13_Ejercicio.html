Ejercicio 2.13: Identificación de Elementos y Atributos de HTML5

Elementos

  • b) td: Elemento que define una celda de datos en una tabla.
  • c) th: Elemento que define una celda de encabezado en una tabla.
  • e) select: Elemento que crea una lista desplegable en un formulario.

Atributos

  • a) width: Atributo que especifica el ancho de un elemento.
  • d) name: Atributo que especifica el nombre de un elemento (común en formularios).
  • f) type: Atributo que especifica el tipo de entrada o elemento.
