Ejercicio 3.4: Verdadero o Falso

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué:

a) Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color.

b) Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos.

c) HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad.

: HTML5 solo valida el formato sintáctico de la dirección de correo electrónico, pero no puede verificar si el correo introducido existe en la realidad.

d) Puede agregar required a cualquiera de los tipos input.

: No se puede agregar el atributo required a ciertos tipos input como hidden, image, button, submit o reset.

e) Puede habilitar autocomplete sólo para ciertos elementos input.

f) El elemento time nos permite identificar una fecha, hora o ambas.

g) El elemento caption proporciona una leyenda para la imagen en un elemento figure.

: El elemento correcto para proporcionar una leyenda dentro de un elemento figure es figcaption (no caption).

h) El elemento details muestra una flecha que apunta a la derecha seguida de un resumen cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary.

: Es al revés: el elemento summary es el que muestra el resumen visible y, al hacer clic, revela el contenido oculto dentro del elemento details.

i) El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.

j) El elemento highlight nos permite resaltar texto.

: El elemento HTML5 correcto para resaltar texto es mark (no existe un elemento llamado highlight).
